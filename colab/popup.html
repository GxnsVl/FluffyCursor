About & privacy

Open source · MIT license. Built with JavaScript, SVG and elapsed-time spring physics. Runs only on colab.research.google.com.

Settings stay in local browser storage. No telemetry, network requests, notebook text collection, or remote scripts. The extension observes cursor geometry and temporarily hides native caret rendering while its overlay is active.

No editor installation files are modified. Disable the effect here or remove the browser extension to return to the native caret. Reload existing Colab tabs after installing, updating, or removing the extension.
